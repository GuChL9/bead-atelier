慢慢串，随心玩

  1. 挑选

    选择珠径，再点击喜欢的材质，珠子就会加入盘中。

  2. 搭配

    成串时拖动珠子换位。点击珠子可调整尺寸、复制或移除；也可以在顺序列表中选择并用前后按钮移动。

  3. 把玩

    切换到散珠互动，拖动一颗珠子撞开其他珠子。点击收拢成串，回到当前搭配顺序。

  4. 留存

    保存到我的搭配，或导出图片与搭配文件。自动草稿只在当前浏览器保存。

快捷键：Ctrl / ⌘ + Z 撤销，Shift + Ctrl / ⌘ + Z 重做。选中珠子后可按 Delete 移除、方向键换位。最多容纳 60 颗。
