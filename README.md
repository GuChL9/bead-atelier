# 珠间 · 自由串珠工作台

一个可以挑选珠子、拖动碰撞和自由搭配手串的静态网页。

## 使用

- 12 种珠子材质, 6 / 8 / 10 / 12 mm 四种珠径
- 散珠模式支持鼠标和触摸拖动、碰撞和圆盘边界
- 成串模式按混合珠径计算圆环, 拖动或使用按钮调整顺序
- 复制、删除、撤销和重做, 最多 60 颗珠子
- 自动草稿、浏览器内保存搭配、JSON 导入导出和 PNG 图片导出
- 桌面与手机布局, 支持键盘调整珠子

搭配存储在当前浏览器, 不会同步到其他设备。需要长期保存或跨设备使用时请导出 JSON 文件。

材质为视觉模拟。参考内围由圆环中心线减去平均珠径估算, 混合珠径、绳结和松紧会影响实物, 不应作为精确手围或购买尺寸依据。

## 本地运行

无需安装前端依赖或执行构建:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。请使用 HTTP 服务, 直接打开本地文件时浏览器可能限制画布图片导出。

## GitHub Pages

仓库包含自动发布工作流。进入 Settings → Pages, 将 Source 设为 GitHub Actions, 之后推送到 main 会自动更新网站。

发布过程只上传网页、珠子图片与本地依赖, 不上传项目文档。

## 实现与素材

- 原生 HTML / CSS / JavaScript, Canvas 2D 绘制
- Matter.js 0.20.0 负责散珠碰撞, [MIT 许可证](vendor/matter-LICENSE.txt)
- 珠子图集为本项目生成的原创视觉素材
- 运行时不依赖 CDN、账号或服务端 API
- 浏览器具备 WebMCP 接口时可读取搭配和添加珠子, 不支持时不影响正常使用

物理效果为俯视二维模拟, 成串为可控圆环布局, 不模拟真实软绳和三维堆叠。
